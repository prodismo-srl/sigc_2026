Procedimiento de Gestión de Servicios de IT Externos

Código: P133-IT-1
Última revisión: 14/1/2026
Rev. N°: 1
Cumple: TISAX, ISO 27001:2022

1 OBJETIVO

Asegurar que servicios cloud, SaaS, o proveedores externos cumplan con los requisitos de seguridad de la información, especialmente para datos críticos (archivos CATIA, SIP/SIP4.0) y clientes automotrices, cumpliendo con los requisitos TISAX, ISO/IEC 27001:2022 y de clientes automotrices.

2 EVALUACIÓN DE RIESGOS PARA SERVICIOS EXTERNOS

Checklist Inicial:

Criterio Evaluación Ejemplo
Tipo de Datos Procesados ¿Maneja datos 🔴 Críticos (CATIA) o 🟠 Altos (SIP/SIP4.0)? Google Drive almacena diseños 3D.
Ubicación del Servidor ¿Cumple GDPR si almacena datos de la UE? AWS región SudAmérica.
Certificaciones ¿Tiene ISO 27001, TISAX, o SOC 2? Microsoft 365 cumple ISO 27001.
Controles de Seguridad ¿Ofrece MFA, cifrado, y logs de acceso? Anydesk registra IPs de acceso.

Herramienta:

Matriz de riesgo con puntuación (ej.: 1-5) por criterio.

3 REQUISITOS LEGALES Y CONTRACTUALES

Cláusulas Obligatorias en Contratos:

  • Protección de Datos:
    "El Proveedor garantizará cifrado AES-256 para datos en tránsito/reposo, cumplimiento con VDA ISA para diseños CATIA."
  • Acceso y Auditoría:
    "El Proveedor permitirá auditorías anuales por parte de Prodismo SRL o clientes (ej.: BMW GS.11)."
  • Respuesta a Incidentes:
    "Notificación de brechas en menos de 24h, con remediación en 72h."

Ejemplo de Requisitos por Cliente:

Cliente Exigencias Clave
VW Prohibido usar Dropbox/WeTransfer (solo plataformas aprobadas).
Mercedes Retención de logs por 6 meses mínimo.

4 ARMONIZACIÓN CON NECESIDADES DE PROTECCIÓN

Matriz de Alineación:

Servicio Externo Activos Asociados Controles Requeridos Estado
Servicio Externo Donweb App Viajes (🟠) Cifrado + MFA + contraseña ✅ Implementado
Anydesk Soporte Remoto (🟠) Logs de acceso. ⚠️ Pendiente MFA
Zoom Reuniones (🔵) Cifrado E2E + grabaciones locales. ❌ No aprobado

Acciones para No Aprobados:

  • Zoom: Reemplazado por Microsoft Teams (cumple TISAX).

5 PROCEDIMIENTO DE ADQUISICIÓN

Flujo de Aprobación:

  1. Solicitud: Equipo de proyecto envía formulario con:
    • Datos involucrados (ej.: "Almacenar archivos CATIA en Servidor Interno solamente").
    • Clasificación CID (🔴/🟠/🔵).
  2. Revisión por IT Manager:
    • Verificar checklist de riesgos.
    • Validar contrato con cláusulas de seguridad.
  3. Implementación:
    • Configurar controles.
    • Capacitar usuarios (ej.: no compartir links públicos en SharePoint).

6 MONITOREO Y AUDITORÍA

Herramientas:

  • Cloud Access Security Broker (CASB): Monitorear uso de servicios no autorizados (ej.: empleados usando Google Drive).
  • Informes Semestrales:
    • % de servicios externos cumpliendo TISAX.
    • Incidentes relacionados (ej.: acceso no autorizado a servicios externos).

Ejemplo de Rechazo de Servicio

Servicio: Zoom

Motivo:

  • No cumple cifrado E2E para reuniones con diseños CATIA (requerido por BMW).

Alternativa Aprobada: Microsoft Teams con:

  • Grabaciones locales.
  • MFA obligatorio.

Recomendaciones Clave

  • Lista Blanca/Aprobada: F525-IT-1 Inventario de Sistemas. Publicar vía mail servicios externos autorizados (ej.: MS Teams, Sharepoint, Anydesk).
  • Penalizaciones: Incluir en contratos multas por incumplimiento.
  • Training: Capacitar en riesgos de "Shadow IT" (ej.: no usar Dropbox para almacenar diseños CATIA).
